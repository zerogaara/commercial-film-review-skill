# 品牌形象片与产品发布片 · 六维通用审片细则

## 1. 叙事与品牌情绪弧线
- **品牌形象片（通常 90s–240s）**：
  - 典型四段式：**开篇立意/格局（15–20%）→ 行业痛点或真实场景（20–25%）→ 制造实力/技术内核/情绪高潮（35–40%）→ 品牌愿景与落版 Packshot（15–20%）**。
  - 常见病：**“企业汇报片/PPT 念稿感”**——按“公司简介 → 厂房航拍 → 荣誉证书 → 领导讲话 → 展望未来”线性平铺，缺乏情绪起伏与视觉隐喻。
- **产品发布片（通常 45s–120s）**：
  - 典型四段式：**悬念/核心痛点（10–15%）→ 产品惊艳亮相 Hero Shot（15–20%）→ 2–3 个核心卖点的视觉化拆解（45–50%）→ 场景回归与参数/型号落版（15–20%）**。
  - 常见病：**卖点贪多求全**，每个特性只给 2 秒配大段小字，观众一个都记不住。

## 2. 构图与摄影语言
- **景别呼吸感**：忌连续 4 个以上同景别/同角度镜头堆砌；宏大空间后应接质感特写（手、材质纹理、光斑、精密结构），形成“大—小—大”的视觉呼吸。
- **主次与留白**：商业片的高级感来自“克制的画面信息量”。检查背景是否杂乱（杂色标识、无关路人、凌乱电线、穿帮反光）。
- **运动方向一致性**：推/拉/摇/移应服从同一视觉动势，忌上一镜向左快速横移、下一镜突然向右急停造成视觉眩晕。

## 3. 剪辑点与节奏
- **ASL（平均镜头时长）参考**：
  - 品牌形象片抒情/铺垫段：`3.0s–5.5s`；高潮蒙太奇段：`0.8s–1.8s`；落版：`4.0s–6.0s`。
  - 产品发布片亮相/科技爆点段：`0.6s–1.5s`；核心工艺/细节展示：`2.0s–3.5s`。
- **切点质量**：
  - 检查动作切点是否在动作发力/速度最快处切（Action Cut），避免在动作停顿、相机刚起稳或将停未停的“犹豫帧”切入/切出。
  - 检查是否善用 **Match Cut（相似构图/颜色/运动匹配剪辑）** 串联不同场景，替代生硬的叠化/闪白转场。
  - 检查 **J-Cut / L-Cut**：声音先于画面 0.5–1.5 秒进入，能让段落过渡像电影一样丝滑。

## 4. 配乐与声音设计
- **响度与动态参考**：
  - 线上发布/展厅大屏通用安全值：Integrated Loudness 约 `-14 LUFS` 至 `-16 LUFS`（广电标准 `-24 LUFS`），True Peak 不超 `-1.0 dBTP`。
  - 警惕 **LRA（响度范围）过平（< 4 LU）**：全片从头炸到尾，没有静音留白和情绪蓄力，高潮反而推不上去。
- **配乐与剪辑关系**：
  - 大段落转折前应有 `Riser / Reverse Cymbal / 乐器抽空` 蓄力，随后在重拍（Downbeat）落大景或 Hero Shot。
  - 旁白出现时，BGM 中频（1kHz–4kHz）应做 EQ 避让或轻微压低（-4 至 -6 dB），避免人声发闷或盖过旁白。
- **音效（SFX / Foley）**：
  - 纯画面配一首 BGM 会显得单薄、像“幻灯片配乐”。加入克制的真实环境音与质感音效（微风、金属轻触、光束脉冲、空间混响）能瞬间拉高制作档次。

## 5. 调色与影调连贯性
- **镜头间一致性**：同场景相邻镜头的**黑位（Lift）、高光色温、肤色和饱和度**不能明显跳变；航拍素材与地面实拍素材之间尤其容易出现“航拍偏青过锐、地面偏暖发灰”的断层。
- **高光与暗部**：检查天空、白色建筑、金属反光是否出现难看的死白裁切（Clipping）；暗部是否有明显的噪点/色块压缩感。
- **调色克制**：商业片忌过度青橙（Teal & Orange）或廉价高饱和滤镜，色彩应服务于品牌主色和材质真实感。

## 6. 文字包装与品牌落版（Packshot）
- **版式克制**：商业片文字不是短视频花字——字号层级清晰（主标/副标/参数最多 2–3 级），字重对比干净，留足边距安全区，忌描边/重投影/花哨弹跳。
- **数据展示**：一个画面只讲 1 个核心数字，数字用等宽或清晰无衬线体，配简洁几何线框或淡入/遮罩划出动画。
- **落版（Packshot）**：结尾 Logo + Slogan 至少保留 `3.5s–5.0s` 静止阅读时间，配乐自然收尾（Tail/Reverb）而非生硬淡出截断。
