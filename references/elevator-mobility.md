# 电梯与垂直交通 · 品牌形象片与产品发布片审片标准

电梯类宣传片与产品发布片的核心审美命题是：**把“密闭钢箱/机电设备”拍出“建筑空间美学 + 绝对平稳静谧 + 高级材质工艺 + 人本安全信任”**。

## 1. 叙事与调性常见雷区
- **避坑“装修样板间 + 机械说明书”**：电梯的终极价值不是铁皮箱子，而是**连接城市天际线、建筑空间与人的从容体验**。检查全片是否只拍了轿厢内景和主机零件，缺少建筑宏大视角与人物舒适松弛的情绪。
- **产品卖点视觉化**：静音、零顿挫启停、曳引机/钢带技术、物联网智慧派梯、抗菌/光幕安全、高端轿厢定制材质——检查是否用**极具说服力的视觉隐喻**（如静止水面无波纹、光影匀速滑过、细节微距）而非干巴巴的字幕堆砌。

## 2. 构图与摄影专项检查
- **建筑几何与对称美学**：
  - 电梯天然属于**强几何、强垂直线条**的品类。检查竖井纵深、厅门开启对称性、轿厢顶灯与扶手线条是否横平竖直（畸变和微歪在电梯片里会极其刺眼，P0 级硬伤）。
- **材质与反光控制（最常见硬伤！）**：
  - 电梯大量使用**不锈钢拉丝、镜面蚀刻、大理石、玻璃、隐藏灯带**。审片时重点检查：
    1. 镜面/金属上有没有穿帮倒影（摄影师、三脚架、杂乱灯光）；
    2. 顶灯和灯带高光是否过曝死白、光晕脏乱；
    3. 拉丝金属质感是否拍出细腻光泽，还是显得灰脏发暗。
- **空间压迫感化解**：轿厢空间狭小，检查机位是否过于逼仄；优秀拍法常借用门框前景、玻璃折射、低角度仰拍或门开瞬间的空间释放感来拓展纵深。

## 3. 运动语言与剪辑节奏专项检查（核心！）
- **“平稳、线性、零顿挫”**：
  - 电梯的品牌心智是**稳与安全**。镜头运动应以**匀速滑轨、平稳升降、克制推拉**为主，忌手持晃动、急推急拉、高频鬼畜闪切（会潜意识传递“抖动、不安全、廉价”的负面感受）。
- **门开/门合与垂直动势衔接**：
  - 厅门左右对称开启、轿厢垂直上升/下降是天然的视觉转场工具（Wipe / Match Cut）。检查切点是否顺着开门速度或垂直升降方向自然承接。
- **节奏参考**：整体比快消/纯科技片更沉稳从容，展示材质与空间时应给足 `2.5s–4.5s` 呼吸感；智慧科技/城市脉动段落可适度加快至 `1.2s–2.0s`。

## 4. 调色与影调专项检查
- **高级感色系**：香槟金/暖白木纹（高端住宅/酒店梯）、冷银/深灰/靛蓝（商业写字楼/高速梯）、克制低饱和的建筑黑白灰基调。
- **关键检查项**：
  - 轿厢内混合色温（顶灯冷白 + 氛围灯暖黄 + 厅外走廊杂色光）极易导致肤色发绿/发青或金属偏色，审片时重点盯人物肤色和中性灰金属是否干净；
  - 暗部要干净沉稳（带细腻对比度），不能发灰发飘。

## 5. 配乐与声音设计专项检查
- **“静谧与阻尼感”是最高级的设计**：
  - 电梯强调静音体验，配乐切忌吵闹、鼓点过密或浮躁电子音。首选**极简钢琴 + 现代弦乐 + 空间氛围声（Minimalist / Architectural Ambient）**，留白越多越显高级。
  - **质感音效（Foley）**：轻柔而有厚重阻尼感的关门声、清脆克制的按键提示音（“叮”声切忌刺耳）、微弱的空气流动感，以及**在强调“静音”卖点时果断抽空音乐留 1 秒近乎寂静的反差设计**。
